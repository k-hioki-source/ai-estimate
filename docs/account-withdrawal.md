# アカウント・退会申請（2026-11-17）

## 実装
- マイページ最下部のアカウント欄に「退会手続きへ」を追加。
- /mypage/account/withdrawal で無料の登録維持とお知らせメール停止を案内。停止はプロフィールへ保存し、案件・請求連絡とは区別。
- 理由は任意。確認チェック後に「退会を申請する」。申請のみで退会完了とは表示しない。
- 未完了案件（見積り・制作・請求を含む）と今後の相談予約件数を本人のRLS下で取得。申請は妨げず、自動キャンセルもしない。
- 既存support_threads / support_messagesへ同時保存。管理者の「メッセージ・相談」に【退会申請】で届く。既存通知経路を使用。
- 未対応申請は再表示。再送・連打も同一の未対応申請に集約。
- 管理者アカウントの申請は権限引継ぎが必要なため対象外。

## データと権限
- 新しい削除権限やサービスキーは追加しない。RPCはSECURITY INVOKER、auth.uid()必須、anon/PUBLICの実行権限なし。既存RLSを維持。
- 本文保存に失敗した場合は受付情報もロールバック。
- アカウント削除・ログイン停止・取引記録削除は自動実行しない。

## 検証
- TypeScriptチェック。
- Next.js本番ビルド。
- 本番DBのトランザクション内で合成会員を用い、申請保存、再送時の重複防止、理由1000文字制限、未ログイン拒否を確認。全件ロールバックし、テスト申請と会員は残さない。通知は送っていない。
- 実会員での申請・通知メール実配信は未実施。

## 確認事項
実際の退会完了処理には、以下の運用決定が必要。
- 進行中案件・未払い請求があるときの退会完了条件。
- 取引記録と個人情報の保存範囲・期間。
- ログイン停止・再登録時の扱いと実際の削除手順。

管理者は申請に返信して案内する。既存問い合わせの「終了」は対応状態であり、アカウントの退会完了を自動実行するものではない。
