# 資料通知・顧客メッセージ改善（2026-11-01）

- 管理者一覧の「新着・要対応」に顧客が追加した未確認reference資料の件数を表示。
- 要対応フィルターにも未確認資料・未読メッセージを含める。

- 一覧の通知はページ読み込み時に取得（リアルタイム購読ではない）。
